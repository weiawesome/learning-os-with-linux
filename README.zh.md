## 為什麼會有這個 repo ?
我之前在工作中遇到一位教授，他提到學習作業系統時，如果只使用 Windows，其實很難真正理解，因為 Windows 是個相對封閉的系統。

相較之下，Linux 非常開放，而且課本裡的許多作業系統概念在 Linux 上都能看到具體實現，這才是學習作業系統的精髓，也讓理解變得更加清晰。

因此藉由這次機會，我把自己的電腦環境從原本的系統改為 Linux，重新開始學習作業系統的原理與實作。
至於為什麼選擇 [Pop!_OS](https://system76.com/pop)，主要是因為女朋友覺得它的介面最漂亮（笑），所以就用它來作為學習的發行版。
