## Why does this repo exist?
Previously at work, I met a professor who mentioned that when learning operating systems, it's actually hard to truly understand them if you only use Windows, since Windows is a relatively closed system.

In contrast, Linux is very open, and many operating system concepts found in textbooks can be seen clearly implemented in Linux. This openness is the essence of learning operating systems and makes understanding these concepts much easier.

So, I took this opportunity to switch my personal computer environment from my previous OS to Linux and began re-learning operating system principles and their implementation. As for why I chose [Pop!_OS](https://system76.com/pop): mainly because my girlfriend thought its interface looked the best (haha), so I decided to use it as my learning distribution.
